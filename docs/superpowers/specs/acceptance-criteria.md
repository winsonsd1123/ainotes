## 需求跟踪矩阵

> **说明：** 建议将此部分放到独立文档 `docs/acceptance-criteria.md`，以便于 AI 生成测试代码时使用。

| **需求 ID** | **功能名称**     | **BDD 验收标准 (Given - When - Then)**                                                                                                              | **验收状态**  |
| :-------- | :----------- | :---------------------------------------------------------------------------------------------------------------------------------------------- | :-------- |
| `REQ-00A` | 用户认证 - 注册成功  | **Given:** 用户在注册页面，输入有效的邮箱和满足长度要求的密码**When:** 点击"注册"按钮**Then:** 账号创建成功，重定向至 `/notes`，显示提示"注册成功"。                                                | `[ ]` 待通过 |
| `REQ-00B` | 用户认证 - 登录成功  | **Given:** 用户在登录页面，输入正确的邮箱和密码**When:** 点击"登录"按钮**Then:** 认证通过，页面重定向至 `/notes` 列表页。                                                              | `[ ]` 待通过 |
| `REQ-00C` | 用户认证 - 登出成功  | **Given:** 用户处于已登录状态**When:** 点击导航栏的"退出登录"按钮**Then:** 清除用户 Session，页面重定向至 `/login` 页面。                                                          | `[ ]` 待通过 |
| `REQ-01`  | 创建笔记 - 标题校验  | **Given:** 用户在创建笔记页面，标题输入栏为空**When:** 点击"保存笔记"按钮**Then:** 提交被拦截，标题输入框显示错误提示"标题不能为空"，且不发起 API 请求。                                                | `[ ]` 待通过 |
| `REQ-02`  | 创建笔记 - 内容校验  | **Given:** 用户在创建笔记页面，内容输入栏为空**When:** 点击"保存笔记"按钮**Then:** 提交被拦截，内容输入框显示错误提示"内容不能为空"，且不发起 API 请求。                                                | `[ ]` 待通过 |
| `REQ-03`  | 创建笔记 - 成功保存  | **Given:** 用户在创建笔记页面，已填写标题和内容**When:** 点击"保存笔记"按钮**Then:** 笔记成功保存到数据库，跳转至笔记详情页，显示 Toast 提示"笔记已保存"。                                              | `[ ]` 待通过 |
| `REQ-04`  | 权限控制 - 未登录拦截 | **Given:** 用户未登录状态**When:** 直接在浏览器地址栏输入 `/notes`**Then:** 被 middleware 拦截，自动跳转至 `/login?redirectUrl=/notes`。                                    | `[ ]` 待通过 |
| `REQ-05`  | 权限控制 - 跨用户访问 | **Given:** 用户 A 登录，尝试访问用户 B 的笔记详情页 `/notes/[b-note-id]`**When:** 发起访问请求**Then:** 返回 403 错误页面，提示"无权访问该笔记"。                                       | `[ ]` 待通过 |
| `REQ-06`  | AI 摘要 - 生成成功 | **Given:** 用户创建了一个新笔记，内容为"Next.js 是 React 服务端渲染框架..."**When:** 笔记保存成功，触发 AI 生成摘要**Then:** 30 秒内笔记详情页显示 AI 生成的中文摘要（100 字以内），笔记状态更新为 `COMPLETED`。 | `[ ]` 待通过 |
| `REQ-07`  | AI 摘要 - 超时处理 | **Given:** 用户创建了一个新笔记，但 LLM API 响应超时**When:** AI 调用超过 30 秒未返回**Then:** 笔记保持 `DRAFT` 状态，详情页显示"摘要生成失败，请重试"，提供"重新生成"按钮。                            | `[ ]` 待通过 |
| `REQ-08`  | 删除笔记 - 权限验证  | **Given:** 用户 A 登录，尝试删除用户 B 的笔记**When:** 调用 `deleteNote()` Server Action**Then:** 返回错误"无权删除该笔记"，数据库不执行删除操作。                                     | `[ ]` 待通过 |
| `REQ-09`  | 输入验证 - 标题超长  | **Given:** 用户在创建笔记页面，标题输入了 250 个字符**When:** 点击"保存笔记"按钮**Then:** 标题被截断为前 200 个字符，显示提示"标题过长，已自动截断"。                                               | `[ ]` 待通过 |
| `REQ-10`  | 并发控制 - 防重复提交 | **Given:** 用户网络卡顿**When:** 连续点击 3 次"保存笔记"按钮**Then:** 只创建 1 条笔记记录，按钮在首次点击后置灰并显示 Loading。                                                         | `[ ]` 待通过 |
